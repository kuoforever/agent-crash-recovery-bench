# Step protocol

> **Status: current module of teaching protocol v1.**

Before a non-trivial step, state the objective, required concepts, why it is
next under [handoff](../../HANDOFF.md), expected evidence, and what failure means.

During execution, explain consequential state transitions, crash windows,
framework settings, command flags, and experimental controls. Summarize repeated
mechanical runs; do not let model or framework terminology hide the actual
effect/trace predicate.

After the step, report the result, what it proves, what it does not prove,
alternative explanations, one interview question, and whether the result is
durable enough for [resume evidence](../resume/).

> Before: Objective ... Concept ... Why now ... Expected evidence ... Failure means ...

> After: Result ... Proves ... Does not prove ... Interview angle ... Next action ...
