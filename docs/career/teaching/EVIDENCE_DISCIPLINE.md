# Evidence and claim discipline

> **Status: current module of teaching protocol v1.**

- A framework demo or local benchmark is not production experience.
- Run sizes, versions, injection phases, and observation windows travel with
  every result.
- `0 duplicates` does not mean exactly-once; the intent ledger trades duplicate
  prevention for `UNCERTAIN_HALT`, including false stops.
- An unobserved retry is not proof that no retry occurs outside the recorded window.
- Repository results do not establish personal authorship; confirm contribution.
- Conversation teaches, [handoff](../../HANDOFF.md) tracks project state, and
  [resume items](../resume/) index only durable results. Do not create a second tracker.
